Implementation Strategy

Since GitHub strips external @font-face URLs, the recommended approach is to convert the text to SVG paths using the chosen font. This guarantees pixel-perfect rendering everywhere, zero font loading, and small file size. Use a tool like opentype.js, Figma's "Outline Stroke", or Inkscape's "Object to Path" to convert.
